<h1 align="center">Alice PC Control</h1>

<p align="center">Управление компьютером на Windows голосом через Яндекс Алису: «Алиса, попроси Мой компьютер выключить компьютер».</p>

---

## Возможности

- 🔒 **Блокировка экрана**: «заблокируй экран».
- ⏻ **Выключение компьютера**: «выключи компьютер».
- 🌐 **Не нужны белый IP, проброс портов, домен и VPN.** Компьютер сам забирает команды из облака Яндекса.
- 💸 **Бесплатно.** Функции для навыков Алисы не тарифицируются, а очередь укладывается в бесплатный лимит.
- 🛡 **Принимаются только запросы от вашего навыка.** Команды, отправленные больше минуты назад, не выполняются.
- 🚀 **Автозапуск вместе с Windows**, в фоне, без окна консоли.

## Как это работает

```
 Вы ──голос──▶ Алиса ──▶ Cloud Function ──▶ Message Queue ◀── агент на ПК
                         (бэкенд навыка)     (очередь команд)   (забирает и выполняет)
```

1. Алиса отправляет фразу в **функцию Yandex Cloud Functions**. Это бэкенд навыка.
2. Функция находит в фразе команду, кладёт её в очередь **Yandex Message Queue** и сразу отвечает Алисе.
3. **Агент** на компьютере постоянно опрашивает очередь, забирает команду и выполняет её.

Агент сам подключается к Яндексу, а входящих подключений к компьютеру нет. Поэтому схема работает за NAT провайдера (серый IP) и без туннелей вроде Cloudflare или ngrok.

## Что понадобится

- Windows 10/11 и [Python 3.10+](https://www.python.org/downloads/). При установке Python отметьте галочку *Add Python to PATH*.
- Аккаунт Яндекса с включённой двухфакторной аутентификацией. Без неё [Яндекс Диалоги](https://dialogs.yandex.ru/developer) не дают создавать навыки.
- Аккаунт [Yandex Cloud](https://console.yandex.cloud) с платёжным аккаунтом. Привязать карту нужно, но за этот проект ничего не списывается (подробнее в разделе [Стоимость](#стоимость)).

## Установка

### 1. Yandex Cloud: очередь и ключ доступа

1. В [консоли Yandex Cloud](https://console.yandex.cloud) откройте каталог (например, `default`).
2. Откройте **Identity and Access Management** → **Сервисные аккаунты** → **Создать**:
   - имя: `alice-pc`;
   - роли: `ymq.reader` и `ymq.writer`.
3. Откройте созданный аккаунт → **Создать новый ключ** → **Статический ключ доступа**. Сохраните **идентификатор ключа** и **секретный ключ**: секрет показывается только один раз.
4. Откройте **Message Queue** → **Создать очередь**: имя `alice-pc`, тип **Стандартная**. Скопируйте **URL** очереди.

### 2. Yandex Cloud: функция навыка

1. Откройте **Cloud Functions** → **Создать функцию** и задайте имя `alice-pc`.
2. Создайте версию:
   - среда выполнения: **Python 3.12**;
   - способ: **Редактор кода**. Создайте файлы [`index.py`](cloud/function/index.py) и [`requirements.txt`](cloud/function/requirements.txt) и вставьте в них содержимое файлов из этого репозитория;
   - точка входа: `index.handler`, таймаут: `5` секунд;
   - сервисный аккаунт: `alice-pc`;
   - переменные окружения:

     | Переменная | Значение |
     |---|---|
     | `QUEUE_URL` | URL очереди из шага 1 |
     | `AWS_ACCESS_KEY_ID` | идентификатор статического ключа |
     | `AWS_SECRET_ACCESS_KEY` | секретный ключ |
     | `SKILL_ID` | ID навыка (добавите после шага 3) |
3. Нажмите **Сохранить изменения**.

### 3. Навык в Яндекс Диалогах

1. Откройте [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) → **Создать диалог** → **Навык**.
2. Заполните поля:
   - **Название**: например, «Мой компьютер»;
   - **Backend**: **Функция в Яндекс Облаке** → `alice-pc`;
   - **Тип доступа**: **Приватный**. Так навык будет доступен только вам и не потребует модерации;
   - остальные обязательные поля: описание, пример запроса, категория и иконка. Иконку можно взять из [`assets/icon.png`](assets/icon.png).
3. Нажмите **Сохранить** → **Опубликовать**.
4. Скопируйте ID навыка из адресной строки (`.../developer/skills/<ID>/...`), впишите его в переменную функции `SKILL_ID` и сохраните новую версию функции.

### 4. Агент на компьютере

```powershell
git clone <ссылка на этот репозиторий>
cd Alice-PC-Control
pip install -r agent/requirements.txt
copy agent\config.example.json agent\config.json
```

Впишите свои значения в `agent/config.json`:

```json
{
  "queue_url": "URL очереди",
  "access_key_id": "идентификатор статического ключа",
  "secret_access_key": "секретный ключ",
  "pause_seconds": 10
}
```

Проверьте, что всё работает. Запустите агент с консолью:

```powershell
python agent/agent.py
```

Затем в Яндекс Диалогах → **Тестирование** напишите «заблокируй экран». Экран должен заблокироваться. Остановить агент можно клавишами `Ctrl+C`.

### 5. Автозапуск

Запустите [`autostart/install_autostart.cmd`](autostart/install_autostart.cmd). Скрипт добавит агент в автозагрузку Windows и сразу запустит его в фоне.

| Скрипт | Что делает |
|---|---|
| `install_autostart.cmd` | добавляет в автозагрузку и запускает |
| `stop_agent.cmd` | останавливает агент |
| `uninstall_autostart.cmd` | убирает из автозагрузки и останавливает |

Лог агента: `agent/agent.log`.

## Использование

Скажите Алисе (в приложении Яндекс, на Станции или в Алисе на Windows, под тем же аккаунтом):

- «Алиса, попроси **Мой компьютер** заблокировать экран»;
- «Алиса, попроси **Мой компьютер** выключить компьютер».

Можно и в два шага: сначала «Алиса, запусти навык Мой компьютер», затем «выключи компьютер».

> Команда выполняется сразу или с задержкой до `pause_seconds` секунд (по умолчанию 10). Подробнее в разделе [Стоимость](#стоимость).

## Своя команда

1. В [`cloud/function/index.py`](cloud/function/index.py) добавьте в `COMMANDS` строку с ключевыми словами, названием команды и ответом Алисы:
   ```python
   (["перезагрузи"], "reboot", "Перезагружаю компьютер"),
   ```
2. В [`agent/agent.py`](agent/agent.py) добавьте действие в `ACTIONS`:
   ```python
   "reboot": lambda: os.system("shutdown /r /t 1"),
   ```
3. Обновите код функции в консоли Yandex Cloud и перезапустите агент (`stop_agent.cmd`, затем `install_autostart.cmd`).

## Стоимость

| Сервис | Бесплатно | Сколько тратит проект |
|---|---|---|
| Cloud Functions | вызовы из навыков Алисы не тарифицируются | — |
| Message Queue | 100 000 запросов в месяц | ~90 000 в месяц |

Агент ждёт команду 20 секунд (long polling), а затем делает паузу `pause_seconds` секунд. При паузе 10 секунд получается около 89 000 запросов в месяц. Если уменьшить паузу, команды будут выполняться быстрее, но лимит будет превышен, и Yandex Cloud начнёт брать небольшую плату.

## Безопасность

- Функция обрабатывает запросы только от навыка с ID из `SKILL_ID`.
- Агент не открывает портов. Читать очередь может только тот, у кого есть статический ключ.
- `agent/config.json` с ключами добавлен в `.gitignore`. **Не публикуйте его.** Если ключ утёк, удалите его в консоли Yandex Cloud и создайте новый.

## Решение проблем

| Проблема | Что проверить |
|---|---|
| Алиса: «Не получилось отправить команду компьютеру» | Переменные окружения функции; роли `ymq.writer`/`ymq.reader` у сервисного аккаунта; логи функции в консоли |
| Ошибка 500 в «Тестировании» | Логи функции. Убедитесь, что `requirements.txt` с `boto3` добавлен в функцию, а точка входа — `index.handler` |
| Алиса отвечает, но ничего не происходит | Запущен ли агент; что написано в `agent/agent.log`; совпадает ли `queue_url` в `config.json` с `QUEUE_URL` функции |
| «Такого навыка нет» | Навык опубликован? Вы вошли в тот же аккаунт Яндекса? Попробуйте написать название навыка текстом |
